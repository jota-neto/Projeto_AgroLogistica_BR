## 📌 Sobre o Projeto

Este projeto simula um cenário real de análise de dados para a empresa fictícia **AgroLogística Brasil**, especializada em transporte e distribuição de grãos no Brasil.

O objetivo principal é identificar **padrões de produção agrícola (milho e soja)** e relacioná-los com **potencial de demanda (população)**, visando otimizar decisões logísticas.

---

## 🎯 Problema de Negócio

Como a AgroLogística Brasil pode:

- Identificar os principais polos produtores?
- Entender a distribuição geográfica da produção?
- Priorizar regiões para implantação de hubs logísticos?
- Otimizar rotas com base em oferta e demanda?

## 🧠 Principais Insights (até o momento)

- Forte concentração da produção de milho no Centro-Oeste  
- Mato Grosso como principal polo produtivo  
- Alta desigualdade entre municípios produtores  
- Produção concentrada em poucos polos estratégicos
